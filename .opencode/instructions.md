# Workflow

Pour toute demande complexe (nouvelle feature, refactor, résolution de bug), suivre ce cycle :

1. **Exploration** — lire la doc projet, explorer le code concerné, comprendre le contexte
2. **Analyse + Options** — présenter un résumé avec 2-4 solutions, leurs pros/cons, via l'outil `question()`
3. **Plan détaillé** — une fois l'option choisie, détailler fichiers à modifier, impact, ordre
4. **Itération** — possibilité d'ajuster le plan via questions ; chaque modification est re-soumise
5. **Validation finale** — question explicite "Ce plan vous convient-il ?" avec choix Oui/Modification
6. **Implémentation** — uniquement après un "go" explicite (pas de devinette, pas d'exécution anticipée)

Les `question()` et `todowrite()` sont les outils clés pour la prise de décision et le suivi.
