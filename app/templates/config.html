Réglages requis pour le suivi par fichier

Configure le renommage de Radarr et Sonarr avant d’utiliser le système.

Pour que le script fonctionne correctement, tu dois garder des noms de fichiers stables et explicites. Si le nommage change trop, le suivi des fichiers devient incohérent.
Radarr

Films

Standard Movie Format

Nom du fichier principal

{Movie Title} ({Release Year}) {imdb-{ImdbId}}
Format du fichier principal. Garde-le stable pour que le suivi reste fiable.

Movie Folder Format

Dossier de rangement

{Movie Title} ({Release Year}) {imdb-{ImdbId}}

L’idée est d’obtenir un nom lisible et unique par film, sans ambiguïté pour le suivi.

Sonarr

Séries

Standard Episode Format

Format recommandé pour les épisodes

{Series TitleYear} - S{season:00}E{episode:00} - {Episode CleanTitle}
Format principal pour les épisodes. Il permet un suivi exact fichier par fichier.

Anime Episode Format

Variante pour les anime

{Series Title} - S{season:00}E{episode:00} - {Episode CleanTitle}

Choisis une variante et garde-la partout. Le plus important est que le nom reste stable d’un fichier à l’autre.

Si tu ne renseignes pas ces formats, SymlinkRepair risque de perdre le lien entre un fichier et son emplacement réel.
